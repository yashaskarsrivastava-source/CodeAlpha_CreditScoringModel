# Credit Scoring Model — CodeAlpha Task 1

## 📌 Objective
Predict whether a person will default on a loan using past financial data.

## 📊 Dataset
- **Source:** Kaggle — Credit Risk Dataset by laotse
- **Rows:** 32,581
- **Columns:** 12

## 🤖 Models Used
| Model | Accuracy | ROC-AUC |
|-------|----------|---------|
| Logistic Regression | 84.59% | 0.8530 |
| Decision Tree | 89.38% | 0.8474 |
| Random Forest | 92.80% | 0.9354 |

## 🏆 Best Model
Random Forest with 92.80% Accuracy and 0.93 ROC-AUC

## 🛠️ Libraries Used
- Pandas, Numpy
- Scikit-learn
- Matplotlib, Seaborn
